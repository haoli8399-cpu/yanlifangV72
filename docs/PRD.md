## 1. 产品定位

### 1.1 解决什么问题

活动行业（演出/年会/庆典/发布会）的供需匹配极度低效：
- 客户有活动需求，但不知道找谁、花多少钱、能做成什么样
- 供应商（演员/舞团/内容团队）有产能，但获客渠道单一
- 中间环节多、沟通成本高、方案可视化难

### 1.2 服务谁

| 用户角色 | 描述 |
|:---|:---|
| 企业客户（Agent 端） | 有活动需求的企业，如年会/庆典/发布会主办方 |
| C 端用户（m 端） | 浏览演出/活动信息的个人用户 |
| 销售/供应商（Supplier 端） | 承接需求的演员、舞团、内容团队 |
| 平台运营（Admin 端） | 平台管理、审核、数据运营 |

### 1.3 核心差异

- **AI 需求提取**：客户用自然语言描述需求 → AI 自动结构化为提案要素
- **可视化方案**：自动生成包含演员/场馆/案例的方案 H5，客户可直接查看
- **增长工具引流**：预算计算器/保险方案生成器等免费工具 → 留资 → 转化为线索
- **全链路闭环**：从获客 → 需求 → 方案 → 报价 → 履约，全流程在线

### 1.4 当前 MVP 范围

| 模块 | 范围 |
|:---|:---|
| Agent 端（PC） | 首页 + AI助手 + 方案发现 + 消息中心 + 需求提交 |
| Admin 端（PC） | 仪表盘 + 客户管理 + SKU管理 + 标签系统 + RBAC + 审计 + AI反馈 |
| Supplier 端（PC） | 工作台 + 线索中心 + 报价管理 + 方案管理 + 商机跟进 + 艺人管理 |
| m 端（移动Web） | 首页 + 发现 + 消息 + 我的 + 需求提交 |
| 增长工具（H5） | 预算计算器 + 保险方案生成器 + 年会方案工具 |
| 客户方案（H5） | 客户专属方案展示页 |
| 小程序 | 品牌色更新（从旧版迁移） |

### 1.5 暂不开发范围（P2）

- 供应链履约（排期/结算/评价）
- 合同管理
- 支付集成
- 汇报方案下载

## 2. 用户角色

| 角色 | 权限 | 主要任务 | 核心痛点 |
|:---|:---|:---|:---|
| 企业客户 | 查看方案/提交需求/接收消息 | 描述活动需求、查看AI生成的方案、联系供应商 | 不知如何表达活动需求、看不懂专业术语 |
| C 端用户 | 浏览内容/查看演出信息 | 发现演出活动 | 信息分散、缺少统一入口 |
| 销售/供应商 | 管理线索/报价/方案/跟进 | 获取线索、快速出方案、报价、跟进客户 | 获客难、出方案慢、报价凭经验 |
| 平台运营 | 全量管理 | 审核内容/管理客户/数据分析/AI Prompt 管理 | 缺少统一运营视图 |

## 3. 核心用户流程

### 3.1 增长工具 → 留资 → 转化

```
用户访问增长工具 H5（预算计算器/保险方案生成器）
→ 回答 6-7 个引导问题
→ AI 生成结果页（预算估算/方案建议）
→ 用户点击「获取完整方案」→ 弹出留资表单
→ 提交 → LeadCaptureModal → 创建线索（leads 表）
→ 线索分配给销售 → CRM 线索中心
```

### 3.2 企业客户提需求 → 方案

```
企业客户登录 Agent PC 端
→ AI Assistant 对话描述需求
→ AI 提取需求要素（RequirementExtractPanel）
→ 生成方案草稿
→ 销售/供应商完善方案
→ 生成客户专属方案 H5（p/$proposalId）
→ 发送给客户 → 客户查看 → 跟进
```

### 3.3 销售跟进线索

```
销售登录 Supplier 工作台
→ 线索中心查看待分配线索
→ 查看线索详情 + 评分（LeadScoreBadge）
→ 创建商机（Opportunity）
→ 关联方案 → 报价 → 跟进记录
→ 状态流转（新线索→跟进中→已报价→已成交/已关闭）
```

## 5. 验收标准（核心功能）

### 5.1 增长工具：预算计算器

| 状态 | 预期 |
|:---|:---|
| 正常流程 | 用户回答 6 个问题 → 显示预算估算结果 → 点击留资 → 弹窗 → 提交成功提示 |
| 空状态 | 首次进入显示第一个问题，无预填 |
| 加载状态 | AI 计算结果时显示 Loading 动画 |
| 错误状态 | 网络异常显示「请稍后重试」+ 重新加载按钮 |
| 边界 | 跳过可选问题不阻断流程 |

### 5.2 客户方案 H5

| 状态 | 预期 |
|:---|:---|
| 正常流程 | 访问 p/$proposalId → 显示完整方案（封面+概述+模块+报价+团队+案例） |
| 空状态 | 无效 proposalId → 显示「方案不存在」 |
| 加载状态 | 方案数据加载中显示骨架屏 |
| 错误状态 | 加载失败显示「加载失败，请稍后重试」 |
| 分享 | 方案被客户打开时记录 view 事件 |

### 5.3 CRM 线索中心

| 状态 | 预期 |
|:---|:---|
| 正常流程 | 列表显示所有线索 → 点击进入详情 → 显示评分+来源+状态 → 可更改状态 |
| 空状态 | 无线索时显示「暂无线索」+ 空状态插画 |
| 加载状态 | 列表加载中显示骨架屏 |
| 错误状态 | 加载失败显示错误提示 + 重试按钮 |
| 权限 | 仅 Supplier 角色可见 |

## 6. 产品变更规则

任何核心业务逻辑变化必须遵守：

```
1. 先更新 docs/PRD.md（本文件）
2. 评估影响范围（前端/后端/数据库/UI）
3. 创建标准任务单（使用 TASK_TEMPLATE.md）
4. 执行开发
5. 更新 STATUS.md
```

**不得先改代码、后补文档。**
