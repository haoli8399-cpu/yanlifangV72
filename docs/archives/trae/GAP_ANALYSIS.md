## 6. 差距优先级

### P0 - 立即必须完成

1. 领域模型与数据库 Schema
2. 权限架构与多租户隔离
3. 认证系统
4. 核心状态机
5. 主服务激活流程
6. 产品不变量测试

### P1 - 重要但可并行

1. API 设计与实现
2. 前端框架与设计系统
3. 组合履约流程
4. 报价与合同系统
5. 收付款与结算
6. AI 系统与错误恢复

### P2 - 完整范围需要

1. 公开发现与内容图谱
2. 历史活动与复购
3. 演员职业资产与成长
4. 平台治理端
5. 平台来源归因与收费
6. 统计指标与运营分析
