# 演立方 V7.2 产品纠偏实施方案

## 一、实施概述

本方案基于《产品纠偏审计报告》，按优先级（P0→P1→P2→P3）执行纠偏工作。

### 实施原则

1. **先做减法**：删除不符合PRD的页面和功能
2. **再做整合**：合并分散的能力到正确的位置
3. **最后做加法**：补充缺失的核心功能
4. **保留后端**：后端API和数据模型完整保留，仅调整前端视图

### 实施阶段

| 阶段 | 内容 | 产出 | 预计时间 |
|:---|:---|:---|:---|
| Phase 1 | P0纠偏：删除错误页面、建立角色差异化导航 | 活动项目空间首页、角色导航 | 2小时 |
| Phase 2 | P0纠偏：补充公开发现端 | 演员/节目/案例/指南列表页 | 2小时 |
| Phase 3 | P1纠偏：方案故事板、领导摘要 | 可视化方案展示 | 2小时 |
| Phase 4 | P1纠偏：等待陪伴模式、历史活动、成果故事 | AI陪伴界面、复购功能 | 2小时 |
| Phase 5 | P2纠偏：演员端优化、平台治理后台 | 移动端友好设计 | 2小时 |
| Phase 6 | 验收测试与最终报告 | 重新验收报告 | 1小时 |

## 二、Phase 1：P0纠偏 - 企业客户首页与角色导航

### 2.1 删除Dashboard页面

**文件**：`/pages/dashboard.tsx`

**操作**：删除该文件

**替代方案**：创建 `/client` 活动项目空间首页

### 2.2 重构Layout组件 - 角色差异化导航

**文件**：`/components/Layout.tsx`

**修改内容**：
- 删除当前统一导航（仪表盘、需求管理、项目管理、供给管理）
- 根据角色显示不同导航：
  - **企业客户**：我的活动、发现、设置
  - **Tenant**：工作台、客户、方案、供给、设置
  - **演员**：我的机会、资料、档期、设置
  - **平台管理员**：治理、审核、监控、设置

### 2.3 创建企业客户活动项目空间首页

**文件**：`/pages/client/index.tsx`

**设计方向**：Client Workspace风格

**核心内容**：
- 当前活动卡片（状态、进度、下一步行动）
- Main Agent对话入口（嵌入页面）
- 方案比较（当前进行中的方案）
- 服务主体信息（主服务Tenant）
- 等待状态提示（如果有等待中事项）

**UI设计**：
- 主活动卡片（突出显示）
- 下一步行动按钮（显眼）
- AI对话气泡（右下角浮动）
- 简洁的信息层级

## 十、风险与应对

| 风险 | 影响 | 应对措施 |
|:---|:---|:---|
| 页面结构变更导致路由失效 | 用户无法访问页面 | 提前规划路由迁移，保持旧路由重定向 |
| 角色导航逻辑复杂 | 开发时间延长 | 分步实现，先完成核心角色 |
| 新页面缺少Mock数据 | 页面显示空 | 提前准备Mock数据结构 |
| 删除页面导致功能缺失 | 用户找不到功能 | 将功能迁移到新位置后再删除 |
