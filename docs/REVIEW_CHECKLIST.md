# 代码复核清单

> **Agent 交付后，Hermes 必须逐项复核。全部打勾才能汇报。**
>
> 已有版本：`~/Desktop/agent-tasks/REVIEW_CHECKLIST.md`  
> 本文件为工程管理体系的标准版本。两个文件内容保持一致。

---

## 复核三层制

### 第一层：自动检查（机器执行）

- [ ] 依赖安装成功（`npm install`）
- [ ] Lint 通过（`npm run lint`）
- [ ] Type Check 零错误（`npx tsc --noEmit`）
- [ ] Build 成功（`npm run build`）
- [ ] 无新增安全漏洞（`npm audit` 无高危）

### 第二层：Hermes 业务复核

#### 文件层面
- [ ] 所有要求的文件都已创建/修改
- [ ] 没有创建多余文件（偏离任务范围）
- [ ] 没有遗漏文件

#### 功能正确性
- [ ] 页面可正常加载（浏览器访问验证）
- [ ] 核心交互可正常工作（点击/筛选/跳转/按钮）
- [ ] 动态路由参数正确生效（如 `$id` 路由）
- [ ] Mock 数据正确渲染
- [ ] 空状态/边界情况有处理
- [ ] 错误状态有展示

#### 代码质量
- [ ] TypeScript 编译零错误
- [ ] 不硬编码颜色（全部用 `var(--yl-*)` 或 Token）
- [ ] 不硬编码字号（全部用 `var(--yl-text-*)`）
- [ ] 不调真实 API（全部 Mock 或 TODO 预留）
- [ ] 代码风格与已有页面一致
- [ ] 无重复导出/死代码/语法错误
- [ ] Import 路径正确

#### 衔接检查
- [ ] 新页面在导航/侧边栏有入口
- [ ] 与已有页面无路由冲突
- [ ] 与已有组件无重复造轮子
- [ ] 类型定义未与已有类型冲突

#### 设计合规
- [ ] 品牌色正确（`#5B4FD6`，非旧色 `#6E59F5`/`#7c3aed`）
- [ ] 按钮/卡片/间距符合 Design System 规范
- [ ] 不出现禁止的视觉方向（电商风/娱乐风/玩具风）
- [ ] 状态标签使用 `<StatusTag />`，非 `<Tag color="xxx">`

#### Token 合规检查 🔴（最容易遗漏）
- [ ] 全局搜索 `fontSize: [0-9]` — 全部为 `var(--yl-text-*)`
- [ ] 全局搜索 `color: "#` — 无硬编码色值
- [ ] 全局搜索 `padding:"[0-9]` / `margin:"[0-9]` — 间距用 `var(--yl-space-*)`
- [ ] 全局搜索 `<Tag color=` — 全部为 `<StatusTag />`

#### 副作用检查
- [ ] 是否修改了任务范围外的文件
- [ ] 是否覆盖了其他 Agent 的代码（对照 git diff 或文件修改时间）
- [ ] 全局搜索残留旧值（如旧品牌色、旧术语）

#### 回归验证
- [ ] 已修复的 Bug 不再复现
- [ ] 相关页面无新增控制台错误

### 第三层：高风险独立复核

以下任务必须增加独立 Agent Review（不由同一 Agent 同时开发和复核）：

- 数据库变更 → 第二个 Agent 复核 SQL
- 权限变更 → 第二个 Agent 复核 RBAC
- 登录认证 → 第二个 Agent 复核安全
- 核心交易/支付 → 两个 Agent + Hermes 三重复核
- 大范围重构 → 第二个 Agent 复核架构
- 生产部署 → Hermes 最终确认

模式示例：
```
Codex 开发 → Qoder/Trae IDE 复核 → Hermes 最终判断
```

## 常见遗漏模式（重点检查）

基于历史经验，以下 Agent 容易遗漏：

| Agent | 高频遗漏 |
|:---|:---|
| Qoder | 漏 `<Outlet />`、重复导出、术语漏改 3-4 处、覆盖 Trae IDE 代码 |
| Trae IDE | Token 合规遗漏、硬编码残留 |
| Codex | 后端代码未经 `tsc --noEmit` 验证 |

**Qoder 交付必须额外检查：**
- `search_files` 搜索重复符号
- 浏览器实测每条新路由/修改路由
- `read_file` 逐文件对照改动清单
