# 标准任务模板

> **Hermes 创建任务时使用本模板。不得直接下发裸需求给 Agent。**
>
> 使用方式：复制本模板 → 填入内容 → 保存为 `~/Desktop/agent-tasks/{Agent名}-TASK-XXX-{描述}.md`

---

## 任务名称

`{Agent名}-TASK-XXX：{一句话描述}`

---

## 1. 任务背景

为什么要做这个任务？用户遇到了什么问题？不做会怎样？

---

## 2. 任务目标

完成后用户能获得什么能力？（一句可验证的话）

---

## 3. 任务类型

标记（可多选）：

- [ ] 产品逻辑
- [ ] UI/UX 设计
- [ ] 前端开发
- [ ] 后端开发
- [ ] 数据库变更
- [ ] API 新增/修改
- [ ] 权限变更
- [ ] 测试补充
- [ ] 部署变更
- [ ] 文档更新
- [ ] Bug 修复
- [ ] 重构

---

## 4. 影响范围

- [ ] 产品逻辑
- [ ] UI/UX
- [ ] 前端代码
- [ ] 后端代码
- [ ] 数据库
- [ ] API 接口
- [ ] 权限系统
- [ ] 测试
- [ ] 部署配置
- [ ] 文档
- [ ] 历史数据

---

## 5. 风险等级

- [ ] Low — 局部修改，影响面极小
- [ ] Medium — 涉及多个文件或模块
- [ ] High — 涉及数据库/API/核心流程
- [ ] Critical — 涉及认证/支付/安全/大范围重构

---

## 6. 前置依赖

- 先读：`docs/PROJECT.md` + 下方指定的事实源章节
- 依赖任务：`TASK-XXX`（如无则写「无」）
- 环境依赖：`Node >= 18` / `PostgreSQL 15` / 等

---

## 7. 开发范围

### 允许修改（必须精确到文件）

```
✅ src/routes/xxx.tsx
✅ src/shared/components/xxx.tsx
```

### 允许新增

```
➕ src/routes/new-page.tsx
➕ src/shared/mock/new-mock.ts
```

### 变更预算

| 项目 | 限制 |
|:---|:---|
| 预计修改文件数 | 不超过 __ 个 |
| 预计新增文件数 | 不超过 __ 个 |
| 允许新增依赖 | 是 / 否 |
| 允许修改数据库 | 是 / 否 |
| 允许修改 API 接口 | 是 / 否 |
| 允许修改 UI 布局 | 是 / 否（如是，L1/L2/L3？） |
| 允许重构 | 是 / 否 |

**超出预算必须停止并汇报 Hermes。**

---

## 8. 禁止修改范围

```
❌ 全局主题/Design Token 文件
❌ 路由结构（router.tsx/__root.tsx）
❌ 权限系统
❌ 数据库结构
❌ 核心 API 接口
❌ 已冻结 UI（见 DESIGN.md UI Baseline）
❌ 以下无关模块：...
```

## 9. 实现要求

### 业务规则
- （描述核心业务逻辑）

### 技术要求
- 不调真实 API，全部使用 Mock 数据
- TypeScript strict mode 零错误
- 必须使用 Design Token（见 `.hermes.md`）

### UI 要求（如涉及）
- 品牌主色 `#5B4FD6`，使用 `var(--yl-primary)`
- 字号使用 Typography Token（`var(--yl-text-*)`）
- 状态标签使用 `<StatusTag />`，禁止 `<Tag color="xxx">`
- 间距使用 Spacing Token（`var(--yl-space-*)`）

### 权限要求（如涉及）
- （角色/权限矩阵）

## 10. 验收标准

**必须可验证。禁止使用模糊词汇。**

| 状态 | 预期行为 |
|:---|:---|
| 正常流程 | 用户点击 X → 系统显示 Y → 数据 Z 被保存 |
| 空状态 | 无数据时显示什么 |
| 加载状态 | Loading 时显示什么 |
| 错误状态 | 错误时显示什么 + 重试方式 |
| 边界情况 | 特殊输入/极限值的行为 |
| 移动端 | 768px 以下如何表现 |

---

## 11. 测试要求

- [ ] `npx tsc --noEmit` 零错误
- [ ] `npm run lint` 通过
- [ ] `npm run build` 成功
- [ ] 核心流程手动测试通过
- [ ] 视觉回归截图对比（前端任务）
- [ ] Type Check 通过

---

## 12. 回滚方案

- 回滚 Commit：（有 Git 时指定）
- 回滚文件：涉及的文件清单
- 数据库回滚：如有，提供回滚 SQL
- 失败恢复：删除新增文件 + 还原修改文件

---

## 13. 提交前自检（Agent 必须逐项确认）

- [ ] `npx tsc --noEmit` 零错误
- [ ] 所有验收标准逐条对照通过
- [ ] 浏览器验证关键页面可正常加载
- [ ] 全局搜索无残留问题关键词
- [ ] 未修改任务范围外的内容
- [ ] 不硬编码颜色/字号/间距（必须用 Token）

**自检通过后才能提交给 Hermes 复核。**
