- ❌ 页面内的"浏览方案库"或"了解更多"入口
- ❌ 页面加载时弹留资弹窗
- ❌ 花哨的粒子动画或渐变背景


### 6.2 状态标签（StatusTag）

**严禁硬编码颜色。** 必须通过 `status` prop 映射到 Design Token：

```typescript
// ✅ 正确
<StatusTag status="已成交" />  // 自动映射到 --color-status-won

// ❌ 禁止
<Tag color="green">已成交</Tag>
```

完整映射表：

| status prop | Token |
|:---|:---|
| `新线索` / `新需求` | `--color-status-new` |
| `已联系` / `需求确认` | `--color-status-progress` |
| `已方案` / `已报价` | `--color-status-proposal` |
