## 1. 响应式设计原则

### 1.1 Mobile-first 与 Desktop-first 策略划分

演立方 V4.7 的 7 个端口根据使用场景与设备特征，分别采用 Mobile-first（移动优先）或 Desktop-first（桌面优先）策略。

| 端口 | 策略 | 原因 | 代码实现方式 |
|------|------|------|-------------|
| Agent PC | Desktop-first | 企业客户在办公场景使用 PC 为主，移动端为降级体验 | 默认桌面样式，小屏 `max-width` 媒体查询降级 |
| Supplier PC | Desktop-first | 销售人员日常作业以 PC 为主，三栏布局依赖宽屏 | 默认三栏，小屏逐步合并为单列 |
| Admin PC | Desktop-first | 管理后台为纯桌面场景，移动端仅做应急查看 | 默认侧栏展开，小屏收为汉堡菜单 |
| 增长工具 H5 | Mobile-first | 获客工具以微信/短信分享打开为主，天然移动场景 | 默认移动样式，大屏 `min-width` 约束最大宽度 |
| 客户方案 H5 | Mobile-first | 方案链接由客户在手机端打开查看 | 默认移动样式，max-width 480px 居中 |
| m 端 | Mobile-first | 移动入口站点，专为手机设计 | 默认移动样式，375-414px 基准 |
| 首页 | Desktop-first | 营销首页以 PC 访问为主，移动端为兼容场景 | 默认桌面网格，小屏降为单列 |

**策略选择原则**:

- **Desktop-first** 端口在代码中使用 `max-width` 媒体查询，从大屏向小屏逐级降级。AntD Col 属性使用 `xs` 作为最小断点，`md`/`lg` 作为升级断点。
- **Mobile-first** 端口在代码中使用 `min-width` 媒体查询，从小屏向大屏逐级增强。Tailwind 类名默认无前缀（移动端），`sm:`/`md:` 为升级断点。
- 所有端口均必须覆盖最小 320px 与最大 1920px 的极端场景测试。

### 1.2 断点系统

演立方 V4.7 统一使用以下 5 级断点系统，与 Tailwind CSS 4.2 及 Ant Design 6.5 栅格断点对齐。

| 断点名 | 像素范围 | Tailwind 前缀 | AntD Col 响应式 | 语义 | 典型设备 |
|--------|----------|--------------|-----------------|------|----------|
| `xs` | `< 768px` | (默认) | `xs` | 超小屏 | 手机竖屏（375-414px） |
| `sm` | `>= 768px` | `sm:` | `sm` | 小屏 | 平板竖屏（768-1023px） |
| `md` | `>= 1024px` | `md:` | `md` | 中屏 | 平板横屏 / 小屏笔记本 |
| `lg` | `>= 1200px` | `lg:` | `lg` | 大屏 | 标准桌面显示器 |
| `xl` | `>= 1440px` | `xl:` | `xl` | 超大屏 | 宽屏显示器 |

**断点规则**:

- 断点值为 `min-width` 语义，即 `sm` 表示 `>= 768px` 时生效。
- Desktop-first 端口在编写 CSS 时，将默认样式设为桌面端，使用 `@media (max-width: 1439px)`、`@media (max-width: 1199px)` 等向下降级。
- Mobile-first 端口将默认样式设为移动端，使用 `@media (min-width: 768px)` 等向上增强。
- AntD Row/Col 组件的响应式属性（`xs`/`sm`/`md`/`lg`/`xl`）始终为 `min-width` 语义，无论端口策略。

### 1.3 栅格系统

演立方 V4.7 采用 **AntD Row/Col 24 栅格系统** 为主要布局工具，Tailwind CSS Grid 作为辅助。

#### AntD Row/Col 约定

```jsx
// 标准用法：gutter 使用 design token，Col 使用响应式属性
<Row gutter={[16, 16]}>
  <Col xs={24} md={12} lg={8}>
    <Card>...</Card>
  </Col>
</Row>
```

| 规则 | 说明 | 示例 |
|------|------|------|
| gutter 取值 | 必须使用 `var(--yl-space-N)` token，禁止硬编码 | `gutter={var(--yl-space-4)}` → 16px |
| Col 占比 | 24 栏制，`xs=24` 为全宽，`md=12` 为半宽，`lg=8` 为三分之一宽 | `xs={24} md={8}` → 移动 1 列、桌面 3 列 |
| 响应式必填 | Col 必须至少指定 `xs`，桌面端补 `md`/`lg` | 禁止仅写 `<Col span={8}>` 无响应式属性 |
| 嵌套栅格 | Row 可嵌套，内层 Row 自动继承父 Col 宽度 | 外层 `lg={12}` 内层再分 `12:12` |

#### Tailwind Grid 约定

```jsx
// 仅在 AntD Row/Col 不适合时使用（如不规则网格、CSS Grid 特性需求）
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
  <div>...</div>
</div>
```

| 规则 | 说明 |
|------|------|
| 优先级 | AntD Row/Col 优先，Tailwind Grid 仅在需要 CSS Grid 特性时使用 |
| 响应式前缀 | 必须从 `grid-cols-1`（移动端）开始，逐级添加 `md:grid-cols-N` |
| gap 取值 | 使用 Tailwind spacing 对应值（`gap-4` = 16px），与 `--yl-space-4` 等值 |
| 禁止场景 | 禁止使用无响应式前缀的 `grid-cols-N`（如仅写 `grid-cols-3`），将导致移动端溢出 |

### 1.4 容器最大宽度

各端口容器最大宽度约束如下，超出宽度时内容居中，两侧留白。

| 端口 | Container maxWidth | 水平 Padding | 说明 |
|------|-------------------|-------------|------|
| Agent 首页 | `1280px` | `var(--yl-space-4)` (16px) | 标准 PC 内容区 |
| Agent AI 对话 | `1440px` | `var(--yl-space-6)` (24px) + `var(--yl-space-4)` (16px) | 宽内容区，对话+面板 |
| Agent 方案发现 | `1280px` | `var(--yl-space-4)` (16px) | 标准 PC 内容区 |
| Supplier 作战台 | `100%` (全宽) | `var(--yl-space-4)` (16px) | 三栏全宽利用 |
| Supplier 跟进中心 | `1280px` | `var(--yl-space-4)` (16px) | 标准 PC 内容区 |
| Admin 后台 | `100%` (全宽) | `var(--yl-space-4)` (16px) | 侧栏 + 全宽内容 |
| 增长工具 H5 | `480px` | `var(--yl-space-4)` (16px) | 居中约束 |
| 客户方案 H5 | `480px` | `var(--yl-space-4)` (16px) | 居中约束 |
| m 端 | `414px` | `var(--yl-space-4)` (16px) | 居中约束 |
| 首页 | `1200px` | `var(--yl-space-4)` (16px) | 标准 PC 内容区 |

**容器规则**:

```css
/* PC 端口容器 */
.yl-container-pc {
  max-width: 1280px;
  margin: 0 auto;
  padding-left: var(--yl-space-4);
  padding-right: var(--yl-space-4);
}

/* H5 端口容器 */
.yl-container-h5 {
  max-width: 480px;
  margin: 0 auto;
  padding-left: var(--yl-space-4);
  padding-right: var(--yl-space-4);
}

/* 全宽端口容器（作战台、Admin） */
.yl-container-fluid {
  width: 100%;
  padding-left: var(--yl-space-4);
  padding-right: var(--yl-space-4);
}
```

**策略**: Desktop-first，最小支持 1024px，768px 以下单列回退。

| 断点范围 | 布局策略 | 容器宽度 | 栅格列数 | 导航行为 |

## 6. 已知问题与修复方案

### 6.1 首页 CSS Grid 无响应式断点

**问题严重度**: 高

**问题描述**: 首页使用内联 CSS Grid `gridTemplateColumns: "repeat(3, 1fr)"` 和 `"repeat(4, 1fr)"`，未设置任何响应式断点。在移动端（< 768px）会导致卡片严重挤压溢出，三列/四列在 375px 屏幕上每列仅约 125px/94px，内容无法阅读。

**影响范围**: 首页 (/) 的核心工具区与适用角色区。

**修复方案**:

```jsx
// 修复前 (错误)
<div style={{ display: 'grid', gridTemplateColumns: 'repeat(3, 1fr)', gap: '16px' }}>
  {tools.map(tool => <ToolCard />)}
</div>

// 修复方案 A: 使用 AntD Row/Col (推荐)
<Row gutter={[16, 16]}>
  {tools.map(tool => (
    <Col key={tool.id} xs={24} sm={12} md={8}>
      <ToolCard data={tool} />
    </Col>
  ))}
</Row>

// 修复方案 B: 使用 Tailwind 响应式类
<div className="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 gap-4">
  {tools.map(tool => <ToolCard key={tool.id} data={tool} />)}
</div>
```

**修复后断点行为**:

| 断点 | 工具卡片 | 角色按钮 |
|------|----------|----------|
| `>= 1024px` (md) | 3 列 (`md=8`) | 4 列 (`lg=6`) |
| `768-1023px` (sm) | 2 列 (`sm=12`) | 2 列 (`sm=12`) |
| `< 768px` (xs) | 1 列 (`xs=24`) | 2 列 (`xs=12`) |

### 6.2 销售作战台固定高度在移动端溢出

**问题严重度**: 高

**问题描述**: 作战台左栏使用 `height: calc(100vh - 260px); min-height: 620px` 固定高度。在移动端（< 1024px）单列布局下，三栏变为 Tab 切换后仍保持固定高度，导致页面大量空白或内容被截断。`min-height: 620px` 在小屏设备上也会导致初始视口内容超出屏幕。

**影响范围**: Supplier 作战台 (/supplier/workspace)。

**修复方案**:

```css
/* 修复前 (错误) */
.workspace-left-card {
  height: calc(100vh - 260px);
  min-height: 620px;
}

/* 修复后 */
.workspace-left-card {
  /* 桌面端保持固定高度 */
  height: calc(100vh - 260px);
  min-height: 620px;
}

/* 平板及以下使用 auto 高度 */
@media (max-width: 1199px) {
  .workspace-left-card {
    height: auto;
    min-height: unset;
    max-height: 70vh; /* 限制最大高度，超出滚动 */
  }
}

@media (max-width: 1023px) {
  .workspace-left-card {
    height: auto;
    min-height: unset;
    max-height: none; /* Tab 切换模式下不限高度 */
  }
}
```

**修复后行为**:

| 断点 | 高度策略 | 说明 |
|------|----------|------|
| `>= 1200px` | `calc(100vh - 260px)`, min 620px | 三栏并排，固定高度 |
| `1024-1199px` | `auto`, max `70vh` | 两栏布局，内容超出滚动 |
| `< 1024px` | `auto` | 单列 Tab 模式，高度自适应内容 |

### 6.4 Admin 表格在小屏横向溢出

**问题严重度**: 中

**问题描述**: Admin 后台数据表格在 768px 以下屏幕未配置横向滚动，列内容被挤压换行或溢出容器。

**影响范围**: Admin 所有含表格的页面。

**修复方案**:

```jsx
import { Table } from 'antd';
import { useBreakpoint } from 'antd-style';

function ResponsiveTable({ columns, ...props }) {
  const breakpoint = useBreakpoint();
  const isMobile = !breakpoint.md; // < 1024px
  const isSmallMobile = !breakpoint.sm; // < 768px

  // 小屏隐藏次要列
  const responsiveColumns = isSmallMobile
    ? columns.filter(col => col.key !== 'description' && col.key !== 'remark')
    : columns;

  return (
    <Table
      columns={responsiveColumns}
      scroll={isMobile ? { x: 800 } : undefined}
      expandable={isSmallMobile ? { expandedRowRender: (record) => <DetailRow record={record} /> } : undefined}
      size={isMobile ? 'small' : 'middle'}
      {...props}
    />
  );
}
```

**修复后行为**:

| 断点 | 表格行为 | 列展示 |
|------|----------|--------|
| `>= 1024px` | 无滚动，完整展示 | 全部列 |
| `768-1023px` | 横向滚动 800px | 全部列（滚动查看） |
| `< 768px` | 横向滚动 600px + 展开行 | 仅主要列，详情展开查看 |

## 附录: 响应式工具函数

### useBreakpoint Hook

```typescript
import { Grid } from 'antd';

const { useBreakpoint } = Grid;

function useResponsive() {
  const screens = useBreakpoint();
  return {
    isMobile: !screens.md,    // < 1024px
    isTablet: screens.md && !screens.lg,  // 1024-1199px
    isDesktop: screens.lg,    // >= 1200px
    isWide: screens.xl,       // >= 1440px
    breakpoint: screens.xl ? 'xl' : screens.lg ? 'lg' : screens.md ? 'md' : screens.sm ? 'sm' : 'xs',
  };
}
```

### Tailwind 断点配置 (tailwind.config)

```javascript
export default {
  theme: {
    screens: {
      xs: '480px',    // H5 大屏约束

      xl: '1440px',   // 桌面大屏
      '2xl': '1920px', // 超宽屏
    },
  },
```
