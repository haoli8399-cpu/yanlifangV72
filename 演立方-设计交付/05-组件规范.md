## 1. 文档概述

### 1.1 文档目标

本文档对演立方 V4.7 版本中所有共享组件进行规范化定义，确保：

- **视觉一致性**：所有页面遵循统一的设计令牌，消除硬编码颜色值
- **交互可预期**：每个组件的状态变体、动画时长、过渡曲线统一管理
- **开发效率**：组件规格可直接映射为 Tailwind 类名 / Ant Design 属性
- **问题修复**：针对 V4.6 及之前版本中发现的色彩对比、禁止色使用等问题给出明确修复方案

### 1.2 组件清单总览

演立方当前共有 **17 个共享组件**，按功能域分类如下：

| 功能域 | 组件 | 说明 |
|--------|------|------|
| 基础 UI | StatusTag / SolutionCard / OpportunityCard / formatters | 标签、卡片、格式化工具 |
| AI 交互 | AIChatPanel / AIFeedbackBar / RequirementExtractPanel | AI 对话、反馈、需求提取 |
| 流程跟踪 | FollowUpTimeline / OpportunityStatusFlow | 时间线、状态流 |
| 数据展示 | DashboardCard / ProposalPreview / LeadScoreBadge | KPI 卡片、方案预览、评分徽章 |
| 表单与弹窗 | LeadCaptureModal / MinimalRequirementForm | 线索收集、兜底表单 |
| H5 工具 | ToolQuestionFlow / ToolResultPage | 提问流程、结果页 |
| 导航 | AppTopBar | 顶部导航栏 |

### 1.3 阅读约定

每个组件规范包含以下标准化小节：

- **视觉示意图**：ASCII 线框图，标注关键尺寸
- **尺寸和间距**：精确到像素的尺寸规格
- **颜色使用规则**：引用设计令牌，禁止硬编码十六进制值
- **状态变体**：所有交互状态的视觉定义
- **使用场景**：适用与不适用场景说明
- **禁止用法**：明确标注 "ISSUE" 的历史问题和禁止模式

       ┌─────────────────────────┐

       │    查看详情    →         │  │ height: 48px (large)

**尺寸和间距**

| 属性 | large | default | compact |
|------|-------|---------|---------|
| 高度 | 48px | 40px | 36px |
| 左右内边距 | 24px | 20px | 16px |
| 字号 | 16px | 14px | 14px |
| 圆角 | 8px | 8px | 8px |
| 图标与文字间距 | 8px | 8px | 6px |

**颜色使用规则**

| 状态 | 背景色 | 文字色 | 边框 |
|------|--------|--------|------|
| default | `--yl-primary` #5B4FD6 | #FFFFFF | 无 |
| hover | `--yl-primary-hover` #4A3FC5 | #FFFFFF | 无 |
| active | `--yl-primary-active` #3D33B3 | #FFFFFF | 无 |
| disabled | `--yl-primary` (opacity 0.4) | #FFFFFF | 无 |
| loading | `--yl-primary` #5B4FD6 | #FFFFFF | 无，左侧显示 Spin |

**状态变体**

```
  Default          Hover            Active          Disabled         Loading
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 提交      │    │ 提交      │    │ 提交      │    │ 提交      │    │ ◌ 提交    │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
 #5B4FD6         #4A3FC5          #3D33B3         opacity:0.4      #5B4FD6
                                                 cursor:not-allowed spin icon旋转
```

**使用场景**
- 页面级主操作（提交表单、确认弹窗）
- 关键转化 CTA（获取方案、确认报价）
- 每个视图区域仅允许存在 **1 个** Primary 按钮

**禁止用法**

> **ISSUE（Agent 首页）**：当前 Agent 首页使用绿色按钮作为主 CTA，违反品牌色规范。  
> **修复**：所有主 CTA 必须使用 `--yl-primary` #5B4FD6，禁止使用绿色作为主操作按钮色。

```
  ❌ 禁止                        ✅ 正确
┌──────────┐                  ┌──────────┐
│  立即开始  │                  │  立即开始  │
└──────────┘                  └──────────┘
 #00875A (绿色)                 #5B4FD6 (品牌紫)
```
