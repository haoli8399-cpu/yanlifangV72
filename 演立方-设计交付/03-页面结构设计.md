# 演立方 V4.7 — 页面结构设计

> 品牌色: #5B4FD6 | 文档版本: V4.7 | 覆盖页面: 10 个关键页面
>
> 本文档定义演立方平台 A 端(客户)、S 端(供应商)、H5(增长工具与客户方案)三大端的页面结构,
> 以 ASCII 线框图为核心交付物,指导后续高保真设计与前端实现。

---

## 一、设计原则

| 原则 | 含义 | 验收标准 |
|------|------|----------|
| **每页一个主焦点** | 同一视口内仅存在一个视觉重心,其余模块以辅助角色退后 | 用户扫视 1 秒内能指出"这页主要让我做什么" |
| **3 秒理解** | 核心信息在首屏 3 秒内可被理解,无需滚动 | 标题 + 主操作 + 上下文在首屏 100% 可见 |
| **分步推进** | 复杂任务拆为渐进步骤,每步认知负荷单一 | 单步最多呈现 1 个决策点 |
| **AI 恰到好处** | AI 能力以辅助者身份出现,不抢占用户决策权 | AI 输出均可被用户修改/拒绝/忽略 |

### 品牌色使用规范

- **主色 #5B4FD6**: 仅用于主按钮、链接文本、选中态、品牌标识
- **禁用**: 绿色按钮(替换原 #52C41A "让AI推荐" 为品牌色主按钮)
- **渐变**: 仅限 Hero 区使用 `linear-gradient(135deg, #1B1550, #5B4FD6)`,提取为 design token `--brand-hero-gradient`,禁止内联
- **功能色**: 成功 #52C41A 仅用于状态指示(非按钮), 警告 #FAAD14, 错误 #FF4D4F

| 模块 | Default | Loading | Empty | Error |
|------|---------|---------|-------|-------|
| AI 输入 Hero | 输入框可输入,场景标签可点击 | 发送后输入框禁用 + Loading 动画 | 无(常驻模块) | AI 服务不可用时显示"服务繁忙"提示 + 重试 |
| 推荐方案卡片 | 3 张方案卡正常展示 | 骨架屏 3 张(░░░) | 显示"暂无推荐,试试搜索" + 跳转链接 | 显示错误提示 + 重试按钮 |

#### 6. 设计要点

- **AI 输入框为唯一主焦点**: Hero 区占据首屏 60% 视觉权重,输入框宽度撑满容器 80%,发送按钮使用品牌色 #5B4FD6(替换原绿色按钮)
- **渐变提取为 Token**: Hero 背景渐变 `#1B1550→#5B4FD6` 提取为 `--brand-hero-gradient`,禁止内联 style
- **最近需求与 Hero 建立连接**: 每张最近需求卡显示进度百分比,点击后直接跳转 A2 对话页并恢复上下文,消除"断裂感"
- **场景标签数量控制**: 桌面端展示 5 个 + "更多",移动端横滑展示,避免标签过多分散输入焦点
- **首屏完整呈现**: Hero + 场景标签在 1080p 屏幕首屏 100% 可见,推荐方案标题可见,符合 3 秒理解原则

| 需求提取面板 | 字段实时更新 | 提取中显示 ░░░ 占位 | 初始状态进度 0%,字段全为 ○ | 隐藏面板,显示"提取服务暂时不可用" |
| 推荐方案预览 | 展示 2 张匹配方案 | 骨架屏 ░░░ | 显示"需求收集中,稍后推荐" | 隐藏此区域 |

#### 6. 设计要点

- **对话区为主焦点**: 占 13/24 栅格,视觉权重最高,输入框固定底部始终可达
- **实时反馈回路**: 右侧提取面板与对话同步更新,用户每发一条消息,提取字段即时变化,建立"AI 在听"的信任感
- **表单出现的时机**: 第 3 轮对话后,当 AI 判断仍有核心字段缺失时,表单以内嵌方式平滑展开在对话流中(非弹窗),不打断对话节奏
- **方案推荐不抢戏**: 右侧推荐方案以 compact 卡片形式出现,匹配度作为辅助信息,核心 CTA 是对话输入而非方案点击
- **兜底区折叠**: 热门方案兜底默认折叠,仅在对话区内容不足一屏时展开,避免分散注意力

- **进度条始终可见**: 顶部进度条让用户知道"还剩多少",降低中途放弃率,品牌色填充增强成就感

- **跳过设计降低摩擦**: 非必答题提供"跳过"选项,用灰色文字弱化,避免用户因不想答某题而退出

#### 6. 设计要点

- **PDF 般的专业质感**: 封面全屏背景图 + 渐变遮罩,章节用 ═══ 分隔线,整体克制不花哨,传递"专业机构出品"的可信感
- **8 段式叙事结构**: 封面(印象) → 摘要(概览) → 需求理解(共鸣) → 推荐方案(核心) → 团队(实力) → 案例(背书) → 服务(保障) → CTA(行动),每段解决一个信任问题
- **推荐方案为内容核心**: ④ 推荐方案是唯一带报价的章节,左图右文 + 环节列表 + 品牌色报价卡,信息密度最高但层次分明
- **底部 CTA 始终可达**: 固定底部的"咨询顾问 + 确认方案"双按钮,用户在任何章节均可直接行动,描边按钮与品牌色按钮主次分明
- **章节标题统一规范**: 每个章节标题 18px 加粗 + 下方 ──── 分隔线,序号 ①②③ 引导阅读顺序,视觉节奏一致
