## 一、铁律（任何页面必须遵守）

### 1.1 禁止硬编码视觉值

```
❌ fontSize: 14
❌ color: "#5B4FD6"
❌ padding: "16px"
❌ borderRadius: 8
❌ background: "#F7F8FA"
```

```
✅ fontSize: "var(--yl-text-body-md)"
✅ color: "var(--yl-primary)"
✅ padding: "var(--yl-space-4)"
✅ borderRadius: "var(--yl-radius-md)"
✅ background: "var(--yl-bg-page)"
```

### 1.2 Typography Token（唯一可用字号）

| Token | 值 | 场景 |
|:---|:---|:---|
| `var(--yl-text-display-lg)` | 36px/700 | 首页主标题 |
| `var(--yl-text-display-md)` | 30px/700 | Hero副标题 |
| `var(--yl-text-display-sm)` | 24px/600 | 页面大标题 |
| `var(--yl-text-heading-1)` | 22px/600 | 模块标题 |
| `var(--yl-text-heading-2)` | 18px/600 | 卡片标题 |
| `var(--yl-text-heading-3)` | 16px/600 | 列表项标题 |
| `var(--yl-text-heading-4)` | 14px/600 | 小标题 |
| `var(--yl-text-body-lg)` | 16px/400 | AI回复、方案描述 |
| `var(--yl-text-body-md)` | 14px/400 | 默认正文 |
| `var(--yl-text-body-sm)` | 13px/400 | 紧凑列表、工作台 |
| `var(--yl-text-caption)` | 12px/400 | 时间戳、标签 |
| `var(--yl-text-caption-xs)` | 11px/400 | 版本号 |
| `var(--yl-text-numeric-lg)` | 32px/700 | 仪表盘核心指标 |
| `var(--yl-text-numeric-md)` | 24px/600 | 卡片数据 |
| `var(--yl-text-numeric-sm)` | 14px/500 | 表格数字 |

### 1.3 Color Token

- 品牌色：`var(--yl-primary)` / `var(--yl-primary-hover)` / `var(--yl-primary-active)` / `var(--yl-primary-subtle)`
- 状态色：必须使用 `<StatusTag status="xxx" />`，禁止 `<Tag color="xxx">`
- 文字色：`var(--yl-text-primary)` / `var(--yl-text-secondary)` / `var(--yl-text-tertiary)`
- 背景色：`var(--yl-bg-page)` / `var(--yl-bg-surface)` / `var(--yl-bg-ai)`
- 边框色：`var(--yl-border-default)` / `var(--yl-border-subtle)` / `var(--yl-border-ai)`

### 1.4 Spacing Token

| Token | 值 | 场景 |
|:---|:---|:---|
| `var(--yl-space-2)` | 8px | 紧凑间距 |
| `var(--yl-space-3)` | 12px | 元素内间距 |
| `var(--yl-space-4)` | 16px | 卡片内边距 |
| `var(--yl-space-6)` | 24px | 模块间距 |

### 1.5 Radius Token

| Token | 值 | 场景 |
|:---|:---|:---|
| `var(--yl-radius-sm)` | 4px | Tag/Badge |
| `var(--yl-radius-md)` | 8px | 按钮/Input |
| `var(--yl-radius-lg)` | 12px | Card/弹窗 |

## 二、组件使用规范

### 2.1 状态标签
```tsx
// ✅ 正确
<StatusTag status="已成交" />
<StatusTag status="新线索" />

// ❌ 禁止
<Tag color="green">已成交</Tag>
<Tag color="#00875A">已成交</Tag>
```

### 2.2 按钮
```tsx
// ✅ 正确 — 使用 Ant Design Button，theme.ts 已全局配置样式
<Button type="primary">主按钮</Button>
<Button>次按钮</Button>

// ❌ 禁止 — 硬编码按钮样式
<button style={{ background: "#5B4FD6", padding: "8px 16px" }}>...</button>
```

### 2.3 AI内容区域
```tsx
// ✅ 正确
<div style={{ background: "var(--yl-bg-ai)", border: "1px solid var(--yl-border-ai)" }}>
  // AI生成的内容
</div>
```

## 三、提交前自检

每个Agent提交代码前必须检查：

- [ ] 全局搜索 `fontSize:` — 全部为 `var(--yl-text-*)`
- [ ] 全局搜索 ` color:`（硬编码色值） — 无 `#` 开头的颜色
- [ ] 全局搜索 `<Tag color=` — 全部替换为 `<StatusTag`
- [ ] 全局搜索 `padding:` / `margin:` — 像素值用 `var(--yl-space-*)`
- [ ] 全局搜索 `borderRadius:` — 像素值用 `var(--yl-radius-*)`
- [ ] `npx tsc --noEmit` 零错误
- [ ] 未修改任务范围外内容

## 四、禁止清单

- ❌ `fontSize: 数字` — 必须用 Typography Token
- ❌ `color: "#xxxxxx"` — 必须用 Color Token
- ❌ `padding: "数字px"` / `margin: "数字px"` — 必须用 Spacing Token
- ❌ `<Tag color="xxx">` — 必须用 StatusTag 组件
- ❌ 全局搜索替换用 sed/grep — 容易误伤，逐文件对照改
- ❌ 修改已有组件的行为逻辑（只改样式）
